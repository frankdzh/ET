# ET框架开发命令与构建流程

## Unity编辑器快捷命令

### F键快捷操作
- **F6**: 编译热重载程序集（`ET -> Compile`）
- **F7**: 运行时热重载代码（`ET -> Reload`）

### ET菜单命令
```
ET/
├── Build Tool          - 构建工具
├── Change Define       - 修改编译宏
├── Compile (F6)        - 编译热重载程序集
├── Reload (F7)         - 热重载代码
├── NavMesh             - 导航网格工具
└── Server Tools        - 服务器工具
```

## 核心开发命令

### 服务端编译
```bash
# 完整编译ET解决方案
dotnet build ET.sln

# 发布Release版本
dotnet build ET.sln -c Release

# 发布Linux版本
dotnet publish -r linux-x64 --no-self-contained -c Release
```

### 工具命令
```bash
# 导出Excel配置为代码
# Unity: ET -> BuildTool -> ExcelExporter
# 命令行: dotnet Tool.exe --AppType=ExcelExporter --Console=1

# 生成protobuf C#文件
# Unity: ET -> BuildTool -> Proto2CS  
# 命令行: dotnet Tool.exe --AppType=Proto2CS --Console=1

# 启动独立服务器
# Unity: ET -> ServerTools -> Start Server(Single Process)
# 命令行: dotnet App.dll --Process=1 --StartConfig=StartConfig/Localhost --Console=1
```

## 标准构建流程

### 开发环境设置
1. **全局配置设置**
   ```
   Assets/Resources/GlobalConfig:
   - AppType: Demo(状态同步) 或 LockStep(帧同步)
   - CodeMode: ClientServer (开发模式)
   - EPlayMode: EditorSimulateMode (编辑器模式)
   ```

2. **编译步骤**
   ```bash
   # 1. Unity中按F6编译热重载程序集
   # 2. 打开ET.sln，编译整个解决方案
   dotnet build ET.sln
   
   # 3. Unity中运行Init场景
   ```

### 打包发布流程

#### 客户端打包
```bash
# 1. 安装HybridCLR
HybridCLR -> Installer -> 安装

# 2. 编译代码
Unity: ET -> Compile (F6)

# 3. 生成HybridCLR相关文件
HybridCLR -> Generate -> All

# 4. 复制AOT DLL
HybridCLR -> CopyAotDlls

# 5. 构建资源包
YooAsset -> AssetBundle Builder:
- BuildPipeline: ScriptableBuildPipeline
- BuildMode: IncrementalBuild  
- CopyBuildinFileOption: ClearAndCopyAll
- 点击 Click Build

# 6. 设置发布模式并构建
Assets/Resources/GlobalConfig:
- EPlayMode: HostPlayMode
Unity: ET -> BuildTool -> BuildPackage
```

#### 服务端部署
```bash
# Windows编译后部署到Linux
dotnet publish -r linux-x64 --no-self-contained -c Release

# 复制必要文件到服务器
cp -r Bin/ /target/server/Bin/
cp -r Config/ /target/server/Config/

# Linux服务器运行
cd /target/server/Bin/
dotnet App.dll --StartConfig=StartConfig/Release --Console=1
```

## 热重载开发流程

### 前提条件
```
Unity Preferences -> General:
ScriptChangesWhilePlaying = RecompileAfterFinishedPlaying
```

### 热重载步骤
1. **运行游戏**: Unity中Play运行游戏
2. **修改代码**: 在Rider/VS中修改Hotfix程序集代码
3. **编译**: 按F6编译或IDE中编译
4. **热重载**: 按F7重载，更改立即生效

### 支持热重载的程序集
- **Unity.Hotfix**: 客户端游戏逻辑
- **Unity.HotfixView**: 客户端表现逻辑  
- **DotNet.Hotfix**: 服务端游戏逻辑

## 服务器启动配置

### 配置环境
- **Localhost**: 本地开发（127.0.0.1）
- **Release**: 生产环境部署
- **Benchmark**: 性能压测环境
- **RouterTest**: 软路由测试环境

### 启动命令
```bash
# 单进程模式（开发）
dotnet App.dll --Process=1 --StartConfig=StartConfig/Localhost --Console=1

# 多进程模式（生产）
dotnet App.dll --AppType=Watcher --StartConfig=StartConfig/Release --Console=1

# 启动MongoDB
mongod --dbpath=db
```

## 常见问题解决

### 编译问题
1. **缺少依赖**: 确保.NET 8已安装，全局翻墙下载NuGet包
2. **程序集引用**: External Tools中不要勾选Registry packages和Build-in packages
3. **IL2CPP扩展**: Unity2022需要安装IL2CPP扩展解决编译API问题

### 运行问题  
1. **管理员权限**: Unity和Rider都需要管理员权限启动（HTTP服务需要）
2. **连接失败**: 检查ET/Logs目录的错误日志
3. **缺少StreamingAsset**: 手动在Assets下创建StreamingAsset文件夹

### 性能优化
1. **F6编译快速**: 只编译热重载程序集，秒级完成
2. **增量构建**: YooAsset使用IncrementalBuild模式
3. **并行开发**: 客户端服务端可同时开发调试

这套开发流程让ET框架实现了极高的开发效率，特别是热重载功能大大提升了迭代速度。
