# ET框架项目概述与架构

## 项目概述

ET (Entity-Task) 是一个Unity3D + .NET Core分布式游戏框架，支持客户端和服务端双端开发。这是8.1版本，采用多线程/多进程架构，基于类似Erlang进程的纤程(Fiber)设计。

## 核心特性

### 双端开发
- **客户端**: Unity3D + C#
- **服务端**: .NET Core + C#
- **代码共享**: 前后端共享核心逻辑代码
- **热重载**: 客户端和服务端都支持运行时热重载

### 架构优势
- **Entity-Component系统**: 所有游戏对象继承自Entity，通过Component添加功能
- **纤程系统**: 轻量级线程，利用多核同时保持单线程开发体验
- **Actor模型**: 进程间实体的位置透明消息传递
- **分布式设计**: 可拆分为多个服务器进程，也可合并为单进程开发

## 程序集结构

### Unity客户端程序集
- **Unity.Core**: 客户端/服务端共享的核心功能（Entity系统、网络、序列化）
- **Unity.Model**: 数据模型和组件（支持热重载）
- **Unity.Hotfix**: 热重载游戏逻辑（客户端和服务端）
- **Unity.HotfixView**: 客户端表现层热重载逻辑
- **Unity.ModelView**: 客户端表现层数据模型
- **Unity.Loader**: 启动引导和资源加载
- **Unity.Editor**: Unity编辑器工具
- **Unity.ThirdParty**: 第三方库

### .NET服务端程序集
- **DotNet.App**: 独立服务器应用程序入口点
- **DotNet.Core**: 服务端核心功能
- **DotNet.Model**: 服务端数据模型
- **DotNet.Hotfix**: 服务端热重载逻辑
- **DotNet.ThirdParty**: 服务端第三方库
- **DotNet.Loader**: 服务端启动加载器

## 核心系统

### Entity-Component系统
```csharp
// 所有游戏对象都是Entity
public class Player : Entity
{
    // 通过添加Component扩展功能
    public void AddComponents()
    {
        this.AddComponent<HealthComponent>();
        this.AddComponent<MovementComponent>();
        this.AddComponent<InventoryComponent>();
    }
}
```

### 网络架构
- **协议支持**: TCP、UDP、KCP、WebSocket
- **自动回退**: UDP不通时自动切换TCP/WebSocket
- **零GC**: MemoryPack序列化实现零GC网络通信
- **软路由**: 防DDoS攻击保护层

### 开发模式
- **Client**: 仅Unity客户端
- **Server**: 专用服务器
- **ClientServer**: 集成客户端+服务端（开发模式）

## 性能特征

### 基准测试数据
- **网络性能**: 平均每秒20万消息吞吐量
- **并发能力**: 单服务器支持15k+并发玩家（64核/128GB测试）
- **内存优化**: MemoryPack序列化实现零GC分配
- **响应延迟**: KCP协议下网络响应极速

### 扩展性
- **水平扩展**: 支持多进程、多机器部署
- **垂直扩展**: 纤程系统充分利用多核性能
- **动态调整**: 运行时创建/销毁纤程和服务

## 开发环境要求

### 必需软件
- **Unity**: 2022.3.15（精确版本要求）
- **.NET**: .NET 8
- **IDE**: JetBrains Rider 2023.3+（官方推荐，VS不官方支持）
- **数据库**: MongoDB（可选）

### 开发建议
- 需要全局VPN下载Unity/NuGet包
- 服务器HTTP服务需要管理员权限启动
- 推荐Windows开发，Linux部署的工作流程

这种架构设计让ET框架成为了一个真正强大、灵活、高性能的分布式游戏开发框架。
