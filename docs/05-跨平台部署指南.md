# ET框架跨平台部署指南

## 跨平台架构优势

ET框架专门为跨平台部署设计，实现了**Windows开发，Linux部署**的理想工作流程。

### 设计理念
- **开发环境**: Windows + Unity + Visual Studio/Rider
- **生产环境**: Linux + .NET Core Runtime
- **无缝迁移**: 编译后直接复制即可运行

## 服务器端跨平台特性

### 纯.NET Core架构
```csharp
// 服务器端完全基于.NET Core，无Unity依赖
public static class Program
{
    public static void Main()
    {
        // 纯.NET代码，可在任何支持.NET的平台运行
        Entry.Init();
        
        Init init = new();
        init.Start();
        
        while (true)
        {
            Thread.Sleep(1);
            try
            {
                init.Update();
                init.LateUpdate();
            }
            catch (Exception e)
            {
                Log.Error(e);
            }
        }
    }
}
```

### 程序集依赖分析
```
服务器端程序集：
├── DotNet.App.dll          # 入口程序集
├── DotNet.Core.dll         # 核心功能（无Unity依赖）
├── DotNet.Model.dll        # 数据模型（纯C#）
├── DotNet.Hotfix.dll       # 热重载逻辑（纯C#）
├── DotNet.ThirdParty.dll   # 第三方库
└── MongoDB.*.dll           # 数据库驱动
```

## Windows到Linux部署流程

### 1. Windows开发环境编译
```bash
# 在Windows开发机上编译
cd /path/to/ET-project

# 编译Debug版本（开发测试）
dotnet build ET.sln -c Debug

# 编译Release版本（生产部署）
dotnet build ET.sln -c Release

# 发布Linux专用版本
dotnet publish -r linux-x64 --no-self-contained -c Release
```

### 2. 自动化发布脚本
```powershell
# Publish-linux-x64.ps1
dotnet publish -r linux-x64 --no-self-contained --no-dependencies -c Release

$path = ".\Publish\linux-x64"

# 清理旧文件
Remove-Item $path\Bin\ -Recurse -ErrorAction Ignore
Remove-Item $path\Config -Recurse -ErrorAction Ignore

# 复制必要文件
Copy-Item .\Bin\linux-x64\publish -Destination $path\Bin -Recurse -Force
Copy-Item .\Config -Destination $path\Config -Recurse -Force

Write-Host "Linux发布包已生成到: $path"
```

### 3. 文件结构分析
```
需要复制到Linux的文件：
├── Bin/                    # 编译后的程序集和可执行文件
│   ├── App.dll            # 主程序
│   ├── DotNet.*.dll       # 业务程序集
│   ├── *.deps.json        # 依赖描述
│   └── *.runtimeconfig.json # 运行时配置
├── Config/                 # 配置文件
│   ├── Json/              # JSON配置
│   ├── Excel/             # Excel导出的配置
│   └── NLog/              # 日志配置
└── Logs/                   # 日志目录（运行时创建）
```

## Linux服务器环境配置

### 1. 安装.NET Runtime
```bash
# Ubuntu/Debian
wget https://packages.microsoft.com/config/ubuntu/20.04/packages-microsoft-prod.deb -O packages-microsoft-prod.deb
sudo dpkg -i packages-microsoft-prod.deb
sudo apt-get update
sudo apt-get install -y dotnet-runtime-8.0

# CentOS/RHEL
sudo dnf install dotnet-runtime-8.0

# 验证安装
dotnet --version
```

### 2. 安装MongoDB（可选）
```bash
# Ubuntu
wget -qO - https://www.mongodb.org/static/pgp/server-7.0.asc | sudo apt-key add -
echo "deb [ arch=amd64,arm64 ] https://repo.mongodb.org/apt/ubuntu focal/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt-get update
sudo apt-get install -y mongodb-org

# 启动MongoDB
sudo systemctl start mongod
sudo systemctl enable mongod
```

### 3. 系统环境优化
```bash
# 设置文件描述符限制
echo "* soft nofile 65536" >> /etc/security/limits.conf
echo "* hard nofile 65536" >> /etc/security/limits.conf

# 设置网络参数
echo "net.core.somaxconn = 65535" >> /etc/sysctl.conf
echo "net.ipv4.tcp_max_syn_backlog = 65535" >> /etc/sysctl.conf
sysctl -p

# 创建运行用户
useradd -r -s /bin/false etserver
```

## 部署和运行

### 1. 上传文件到Linux
```bash
# 使用rsync同步（推荐）
rsync -avz --delete ./Publish/linux-x64/ user@server:/opt/etserver/

# 或使用scp复制
scp -r ./Publish/linux-x64/* user@server:/opt/etserver/

# 设置权限
ssh user@server "sudo chown -R etserver:etserver /opt/etserver"
ssh user@server "chmod +x /opt/etserver/Bin/App"
```

### 2. Linux服务器运行
```bash
cd /opt/etserver/Bin

# 直接运行（前台）
dotnet App.dll --StartConfig=StartConfig/Release --Console=1

# 后台运行
nohup dotnet App.dll --StartConfig=StartConfig/Release --Console=1 > ../Logs/server.log 2>&1 &

# 使用systemd服务运行（推荐）
sudo systemctl start etserver
sudo systemctl enable etserver
```

### 3. Systemd服务配置
```ini
# /etc/systemd/system/etserver.service
[Unit]
Description=ET Game Server
After=network.target

[Service]
Type=simple
User=etserver
WorkingDirectory=/opt/etserver/Bin
ExecStart=/usr/bin/dotnet App.dll --StartConfig=StartConfig/Release --Console=1
Restart=always
RestartSec=10
StandardOutput=journal
StandardError=journal
SyslogIdentifier=etserver

[Install]
WantedBy=multi-user.target
```

### 3. 性能监控脚本
```bash
#!/bin/bash
# monitor.sh
while true; do
    echo "$(date): Memory: $(free -m | grep Mem | awk '{print $3}')MB, CPU: $(top -bn1 | grep load | awk '{printf "%.2f%%", $(NF-2)}')"
    
    # 检查服务是否运行
    if ! pgrep -f "App.dll" > /dev/null; then
        echo "$(date): Server is down, restarting..."
        systemctl restart etserver
    fi
    
    sleep 60
done
```

## 自动化部署

### 1. CI/CD脚本示例
```yaml
# .github/workflows/deploy.yml
name: Deploy to Linux

on:
  push:
    branches: [ main ]

jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
    - uses: actions/checkout@v2
    
    - name: Setup .NET
      uses: actions/setup-dotnet@v1
      with:
        dotnet-version: 8.0.x
        
    - name: Build
      run: dotnet publish -r linux-x64 -c Release
      
    - name: Deploy to server
      run: |
        rsync -avz --delete ./Publish/linux-x64/ ${{ secrets.SERVER_USER }}@${{ secrets.SERVER_HOST }}:/opt/etserver/
        ssh ${{ secrets.SERVER_USER }}@${{ secrets.SERVER_HOST }} "sudo systemctl restart etserver"
```

### 2. 热更新部署
```bash
#!/bin/bash
# hot_update.sh - 热更新脚本

echo "开始热更新..."

# 1. 备份当前版本
cp -r /opt/etserver/Bin /opt/etserver/Bin.backup.$(date +%Y%m%d_%H%M%S)

# 2. 复制新版本（只复制Hotfix相关）
rsync -avz ./NewVersion/Bin/*Hotfix* /opt/etserver/Bin/

# 3. 发送热重载信号（如果服务器支持）
# curl -X POST http://localhost:8080/api/reload

echo "热更新完成"
```

## 容器化部署（Docker）

### 1. Dockerfile
```dockerfile
# Dockerfile
FROM mcr.microsoft.com/dotnet/aspnet:8.0-alpine

WORKDIR /app

# 复制应用文件
COPY Bin/ ./Bin/
COPY Config/ ./Config/

# 设置权限
RUN chmod +x ./Bin/App

# 暴露端口
EXPOSE 10002 20000

# 启动命令
CMD ["dotnet", "./Bin/App.dll", "--StartConfig=StartConfig/Release", "--Console=1"]
```

### 2. Docker Compose
```yaml
# docker-compose.yml
version: '3.8'

services:
  etserver:
    build: .
    ports:
      - "10002:10002"
      - "20000:20000"
    environment:
      - ASPNETCORE_ENVIRONMENT=Production
    volumes:
      - ./Logs:/app/Logs
      - ./Config:/app/Config
    depends_on:
      - mongodb
    restart: unless-stopped

  mongodb:
    image: mongo:7.0
    ports:
      - "27017:27017"
    environment:
      - MONGO_INITDB_ROOT_USERNAME=admin
      - MONGO_INITDB_ROOT_PASSWORD=password
    volumes:
      - mongodb_data:/data/db
    restart: unless-stopped

volumes:
  mongodb_data:
```

## 性能优化

### 1. Linux系统优化
```bash
# 网络优化
echo 'net.core.rmem_max = 134217728' >> /etc/sysctl.conf
echo 'net.core.wmem_max = 134217728' >> /etc/sysctl.conf
echo 'net.ipv4.tcp_rmem = 4096 87380 134217728' >> /etc/sysctl.conf
echo 'net.ipv4.tcp_wmem = 4096 65536 134217728' >> /etc/sysctl.conf

# CPU优化
echo 'kernel.sched_migration_cost_ns = 5000000' >> /etc/sysctl.conf
```

### 2. .NET运行时优化
```bash
# 环境变量优化
export DOTNET_GCServer=1              # 启用服务器GC
export DOTNET_GCConcurrent=1          # 启用并发GC
export DOTNET_gcTrimCommitOnLowMemory=1 # 低内存时释放内存
```

这种跨平台部署方案让ET框架能够充分利用Windows的开发便利性和Linux的服务器性能优势，实现了理想的开发生产环境分离。
